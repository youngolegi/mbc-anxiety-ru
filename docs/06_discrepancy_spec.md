# Спецификация: слой расхождений «самоотчёт клиента × оценка терапевта»

> **Статус:** черновик на согласовании автора (задача №4 ROADMAP). Кода нет.
> Разметка: [замер] / [интерпретация автора] / [моя склейка]; доказательность — твёрдо / умеренно / шатко.

## 1. Зачем и чего модуль не делает

**Зачем.** Терапевт и клиент видят разное. Терапевты плохо замечают ухудшение «на глаз»:
в Hannan et al. (2005) из 40 реально ухудшившихся клиентов терапевты верно предсказали одного
[замер; умеренно — одно исследование]. Сопоставление самоотчёта с оценкой терапевта показывает
места, где картины расходятся, — это повод спросить, а не ответ.

**Принцип.** Расхождение — тема для разговора, не вердикт. Модуль не решает, кто прав,
не исправляет ни один балл и не вмешивается в светофор.

**Не делает никогда:**
- не обращается к клиенту — вывод только для терапевта;
- не формулирует оценок вида «клиент преуменьшает» или «терапевт ошибается»;
- не ставит диагнозов и не даёт рекомендаций по лечению;
- не использует ИИ: третий источник (темы из свободного текста) — трек Г, после юридической проверки.

**Зависимость.** Нужна ли терапевтам эта функция, проверяет блок 5 интервью трека А (гипотеза H5).
Модуль проектируется под MVP (трек В), но его ценность не подтверждена [интерпретация автора].

## 2. Источники и почему их нельзя сравнивать «в лоб»

| | Самоотчёт клиента | Оценка терапевта |
|---|---|---|
| Шкала | GAD-7 (или другая шкала из `measures.py`) | CGI-S — общее клиническое впечатление, тяжесть |
| Структура | 7 пунктов, 0–21 | 1 пункт, 1–7 (7 — тяжелее всего) |
| Что измеряет | симптомы тревоги | общую тяжесть состояния, включая функционирование и другие проблемы |
| Окно | последние 2 недели | состояние на сессии, относительно опыта терапевта с похожими клиентами — сверить с первоисточником |
| Надёжное изменение | порог из `measures.py` (GAD-7 — 4) | не установлен для одного пункта — эвристика |
| Источник | `measures.py` | Guy, 1976 (ECDEU Assessment Manual) — сверить с первоисточником |

Тексты якорей CGI-S в репозитории не хранятся (правило 2): только структура 1–7.

**Следствие.** Сравнивать уровни (GAD-7 = 12 «это сколько по CGI-S?») нельзя без таблицы
соответствия. Проверенной таблицы GAD-7 ↔ CGI-S я не нашёл [нет данных — это не данные против;
сверить с литературой]. Поэтому основной тип расхождения сравнивает каждый источник **с самим
собой**: направление изменения у клиента и у терапевта.

## 3. Основной тип: расхождение направлений

Для каждой пары сессий «базовая → текущая», где есть и засчитанный самоотчёт, и оценка терапевта:

- **клиент** — надёжное изменение по своей шкале: `classify_change` с порогом шкалы (как в статусе);
- **терапевт** — изменение CGI-S не меньше `cgi_threshold` баллов. Порога надёжного изменения
  для CGI-S нет, поэтому параметр обязательный, без значения по умолчанию (дух правила 3).
  Кандидаты — 1 или 2 балла, выбор — эвристика до калибровки на данных MVP.

```
                       терапевт: лучше     без изменений        хуже
клиент: лучше              согласие        одна сторона         ПРОТИВОПОЛОЖНО
клиент: без изменений   одна сторона         согласие         одна сторона
клиент: хуже            ПРОТИВОПОЛОЖНО     одна сторона          согласие
```

| Тип | Условие | Сила |
|---|---|---|
| `OPPOSITE` | изменения в противоположные стороны | основной сигнал |
| `ONE_SIDED` | меняется одна сторона, другая — нет | слабее; показывать — решение автора (раздел 8) |
| согласие | одинаковое направление | не выводится |

**Устойчивость.** Для каждого расхождения считается, сколько последних пар сессий подряд оно держится
(`persisted`). Порога «показывать только с 2-й сессии» нет: данные не прячутся, но «впервые»
и «держится 3 сессии» подписаны по-разному [моя склейка — предложение].

## 4. Независимость оценки терапевта

Если терапевт ставит CGI-S **после** того, как увидел самоотчёт этой сессии, оценки сближаются
(эффект якоря), и расхождений будет меньше, чем есть [моя склейка — механизм известен,
величина для CGI-S неизвестна]. Поэтому:

- у оценки есть обязательный флаг `blind` — «поставлена до просмотра самоотчёта этой сессии»;
- расхождение по неслепой оценке выводится с пометкой «оценка дана после просмотра самоотчёта —
  расхождение может быть занижено»;
- для MVP: интерфейс просит CGI-S до показа баллов клиента [продуктовое требование].

## 5. Подготовка данных

- Пара — сессия, где есть и самоотчёт, и CGI-S. Сессии только с одним источником в сравнение
  не идут и перечисляются как «без пары».
- Незасчитанный самоотчёт (`total=None`) — как в отчёте: в сравнение не идёт.
- Пересчитанный из-за пропусков самоотчёт идёт с пометкой, как в отчёте.
- Базовая линия — первая пара; текущая — последняя пара.
- CGI-S принимается только целым 1–7. Для этого CGI-S добавляется в `measures.py` как шкала
  из одного пункта с диапазоном 1–7, без порогов, и проходит обычный `score()`.

## 6. Вывод: контракт расхождения

Как у гипотез ИИ: без альтернативного объяснения и вопроса расхождение не создаётся.

| Поле | Содержание |
|---|---|
| `kind` | `OPPOSITE` / `ONE_SIDED` |
| `sessions` | базовая и текущая сессии пары |
| `client` | баллы (база → сейчас), изменение `Change`, пометка пересчёта |
| `therapist` | CGI-S (база → сейчас), направление, флаг `blind` |
| `persisted` | сколько последних пар подряд держится расхождение |
| `alternatives` | непустой список альтернативных объяснений |
| `question` | один нейтральный вопрос, который терапевт может задать на сессии |

**Черновик альтернатив** [моя склейка — на правку автору]:

*Клиент лучше, терапевт видит хуже:*
- разные окна: самоотчёт — за 2 недели, оценка — по одной сессии;
- разные конструкты: тревога против общей тяжести (функционирование, другие проблемы);
- на сессии обсуждался трудный материал — «здесь и сейчас» хуже, чем неделя в целом;
- однопунктовая оценка шумная.

*Клиент хуже, терапевт видит лучше:*
- экспозиция: клиент меньше избегает и чаще встречается с триггерами — дистресс в самоотчёте
  растёт, а поведенчески это прогресс (см. правило 6);
- после психообразования клиент точнее замечает и называет тревогу;
- события недели, о которых терапевт не знает;
- разные окна и конструкты.

*Одна сторона видит изменение:* разные окна; изменение у другой стороны ниже её порога; шум.

**Черновик вопросов для сессии:** «Как бы вы сами описали, что изменилось за последние недели?»;
«Было ли на этой неделе что-то, о чём мы ещё не говорили?».

**Запрещённые формулировки** (тест следит): «преувеличивает», «преуменьшает», «скрывает»,
«неправ», «ошибается», «на самом деле».

## 7. Место в отчёте

Отдельный блок «РАСХОЖДЕНИЯ — темы для разговора» после светофора и статуса. На светофор
расхождения не влияют: у светофора своя задача (безопасность и траектория), у расхождений —
вопрос для сессии [моя склейка — предложение].

## 8. Решения автора до кода

1. **Основной тип** — расхождение направлений, а не уровней (раздел 3). Уровневое сравнение —
   только после калибровки на данных MVP. Согласен?
2. **CGI-S или CGI-I.** Вместо разности CGI-S терапевт может напрямую оценивать улучшение (CGI-I,
   1–7). Это прямая оценка изменения без вычитания двух шумных оценок, но плюс вопрос к «10 секундам
   после сессии» (H5: 1–2 вопроса). v1 — на CGI-S?
3. **`cgi_threshold`** — обязательный параметр без значения по умолчанию или значение по умолчанию
   1 с пометкой «эвристика»?
4. **`ONE_SIDED`** — выводить в v1 или только `OPPOSITE`?
5. **Флаг `blind`** — обязательный (раздел 4)?
6. **Альтернативы и вопросы** (раздел 6) — правка автора: это клинический текст.

## 9. План тестов (после согласования)

- все 9 клеток матрицы направлений, включая границы порогов клиента и терапевта;
- пары сессий: самоотчёт без CGI-S и наоборот — «без пары»; незасчитанные — не в сравнении;
  пересчитанные — с пометкой;
- `persisted`: 1 при первом появлении, N при N подряд, сброс при согласии;
- `blind=False` даёт пометку о возможном занижении;
- CGI-S вне 1–7, дробный, `bool` — ошибка; `cgi_threshold` обязателен;
- контракт: пустые альтернативы или вопрос — ошибка;
- текст: ни одной запрещённой формулировки из раздела 6;
- синтетические данные; мутационная проверка.

## 10. Статус доказательности

| Утверждение | Статус |
|---|---|
| Терапевты плохо замечают ухудшение без замеров (Hannan et al., 2005) | умеренно — одно исследование |
| Самоотчёт и оценка клинициста измеряют разное и расходятся | умеренно — сверить с первоисточниками (литература о расхождении patient-reported и clinician-rated) |
| Надёжное изменение для CGI-S в 1 или 2 балла | шатко — эвристика |
| Эффект якоря при неслепой оценке | умеренно для механизма, величина для CGI-S — нет данных |
| Расхождения полезны терапевту | нет данных — проверяет трек А (H5) |
